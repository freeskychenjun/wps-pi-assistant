# pi 文档助手（WPS 加载项）

在 WPS 文字右侧任务窗格里和 pi agent 聊天，agent 直接在**你正打开的文档**上以**修订模式**改字、加批注、给表格加行、插入段落，你能逐条接受/拒绝，也能一轮一轮地撤销它做过的改动。

不依赖 DSH，只要本机有 Node + pi 即可用。

---

## 一、启动（两步，之后不用再管）

### 1. 启动桥接服务

双击 `start-bridge.cmd`。看到下面这行就说明起来了：

```
[pi-assistant] bridge started on 127.0.0.1:3987
```

重复双击是安全的，会提示 `already running`。

> 桥接进程同时干两件事：① 管 pi 子进程、转发流式输出；② **直接托管加载项页面**（http://127.0.0.1:3987/addin/）。所以它必须在 WPS 之前或同时起来——它没起，WPS 里的「AI 助手」选项卡就打不开侧栏。

### 2. 打开 WPS（侧栏会自动弹出）

首次加载会弹「加载项 pi-assistant（位于 http://127.0.0.1:3987/addin）首次加载，是否信任？」，点**确定**（只需一次，之后持久记住）。

之后每次启动 WPS，侧栏会**自动打开**；若手动关掉了，点「AI 助手」→「打开侧栏」再叫出来。侧栏徽标显示绿色「已连接」即就绪。

### 3. 配模型（只需一次）

侧栏展开「▸ 模型配置」，填：

| 项 | 说明 |
|---|---|
| provider | 如 `anthropic`、`openai`、`deepseek`；留空用 pi 默认 |
| model | 模型 ID；留空用默认 |
| API Key | 留空则沿用 pi 全局配置里的 key |

点「保存并启动」。配置存在 WPS 的 PluginStorage 里，下次打开侧栏会自动按上次配置启动。

## 二、日常使用

1. 在文档里把光标放到**要改的段落**（或选中要改的文字；**光标在表格里就自动带整张表**）；
2. 侧栏输入需求，例如：
   - 「把这段文字改得更正式一些，像正式公文的语气」
   - 「这段话再精简一些，控制在十五字以内」
   - 「给这句话加个批注，说明这里的依据是 2024 年实测数据」
   - 「在李家渡这一行后面新增一行：梅港、24.05、正常」（光标在表格里）
   - 「在表后说明那段之后新增一段：复核人：陈鋆，日期：2026-11-11」
   - 「在第二段之后插入图片 D:\图\断面图.png，宽度 12 厘米」（**图片路径必须是本机能访问的本地文件**）
   - 「在表后说明那段之后新建一个表格，表头是 站名、流量、说明，数据两行：梅港、1250、正常；虎山、980、偏低」
   - 「在表头「水位(m)」右侧插入一列，表头「流量(m³/s)」，数据依次 1250、980、760」
   - 「把「梅港」和「虎山」两个单元格合并」「把表头「测站」拆成 1 行 2 列」
   - 「把「外洲」这一行删掉」「把「备注」这一列删掉」「表头行加粗居中」「备注列宽设为 3 厘米」「表头跨页重复」「表格按内容自适应」
   - **带技能的任务**：「用 datum-conversion 技能查出外洲站的 85 基准面修正值，然后把这一行的水位换算成 85 基准面并改进表格」
   - 「用 frequency-analysis 技能把这几年的洪峰流量排个频，结果按 频率/流量 两列加进表格」
3. 按 **Ctrl+Enter** 或点「发送」。

**上下文下拉**（默认「当前段落」）决定这次自动带给 agent 的内容：选中内容 / 当前段落 / 当前表格 / 全文 / 不附带。光标在表格内时，前三种都会自动升级成「整张表格（行内单元格以 | 分隔）」。

> 全文模式有 6000 字上限（超出截断）。长文档建议用「当前段落」。

4. agent 回复先说一句「改了什么」，然后文档里出现**红字修订**（或批注）；
5. 到「审阅」里逐条**接受/拒绝**——不想要就拒绝，等于逐条撤销。

### 三个便利用法

| 功能 | 说明 |
|---|---|
| **撤销上轮 AI 修订** | 面板底部按钮（或 **Ctrl+Shift+Z**），一次撤一轮，可连续撤多轮（按钮上会显示「可撤销 N 轮」）。撤销是**文本级还原**：按记录把 agent 改过的文字改回去；删除类改动请到「审阅」里拒绝修订。撤销"插入的段落"会留下一个空行，手动删掉即可。 |
| **对话随文档走** | 每个文档（已保存按路径、未保存按窗口句柄）绑一条独立会话，重开文档/重启 WPS 后侧栏会自动带出该文档之前的对话（灰色分隔线「以下是本文档之前的对话」）。 |
| **新对话 / 历史** | 面板顶部「模型配置」右边两个链接：「新对话」在当前文档下另起一条会话（旧的不会丢）；「历史」列出本文档的所有会话（标题取第一条需求、带时间），点一条即切过去。也可直接输入 `/new`、`/sessions`。**新建文档先聊后保存**时，保存那一刻会把会话自动接到新路径上，不会失忆。 |
| **清理旧对话** | 在「历史」列表最下面点「🧹 清理旧对话」：先只统计（每份文档保留最近 20 条、超过 30 天的清掉，当前对话永远保留），再点「🧹 确认清理 N 条」才真正删。清理完列表会刷新并显示释放了多少 KB。 |
| **历史里的工具痕迹** | 某轮回复用过技能/工具时，那条回复下面会有一行灰字「⚙ 用过 bash、read」，重开文档也能看到（记录存在 `tool-log.json`）。 |
| **接管标记** | 处理期间 WPS 标签页标题变成「〔AI〕你的文档名」，完成后自动还原。看到前缀说明 agent 正在动这份文档，别同时手动改。 |

## 三、它能做什么 / 不能做什么

**能**：改写、润色、精简、扩写、换语气、批量替换指定文字、按指令逐段改、加批注、**改表格单元格**、**给表格加整行**、**在指定段落后插入新段落**、删除指定文字、**插入本地图片（按比例缩放）**、**新建表格（表头自动加粗居中）**、**表格结构调整**（合并/拆分单元格、插入列、删除行列、表头加粗居中、列宽行高、表头跨页重复、按内容自适应）、**调用本机技能**（水文计算、资料查询、单位/基面换算等，见下）。

**技能与工具（v2）**：pi 以 `--skill ~/.claude/skills --tools read,bash,ls,find,grep` 启动，即 **100+ 个 Claude 技能 + 只读/执行工具**。典型用法是「先算/先查，再把结果写进文档」——例如查水文数据库、基面换算、排频、暴雨参数查算。调用时面板会显示灰色小字「⚙ 调用工具：bash」。为避免跑偏，system prompt 限制一次任务最多调用 0～3 次工具。

**暂不能**：
- 公式/脚注写入（只能只读带进上下文）；域代码、目录、页眉页脚
- 自己"翻页找内容"（它只看到你给的那段/选区/表格/全文）
- 多文档同时操作（一次只操作当前活动文档，别的文档的回复会被丢弃）
- 从网络/剪贴板取图（图片必须是本机已存在的文件路径）
- 表格结构改动**不参与一键撤销**（撤销按钮只管文字/批注/加行），要退结构改动请在 WPS 里按 Ctrl+Z

**安全边界**：pi 只开了**只读 + 执行**类工具（`read` / `ls` / `find` / `grep` / `bash`），**没有** `write` / `edit`——它不能直接改盘，所有文档改动必须经过「侧栏 → 修订写回」这条路。system prompt 里也明令禁止用 bash 去改 .docx/.xlsx、或调用 `docx-paragraph-polish` / `minimax-docx` 这类**离线改磁盘文件**的技能（那些技能改的是磁盘副本，你眼前这份文档不会变）。

## 四、出问题怎么办

| 现象 | 处理 |
|---|---|
| 徽标「桥接未运行」 | 双击 `start-bridge.cmd` |
| 没有「AI 助手」选项卡 | 桥接没起（WPS 启动时连不上 3987 就跳过加载）；起桥接后重启 WPS |
| 发送后没反应 | 检查桥接进程是否还在；点「AI 助手」→「打开JS调试器」看 Console 报错 |
| 「pi 未启动，请先保存配置」 | 展开模型配置，点一次「保存并启动」 |
| 修订位置不对 | 拒绝那条修订，重新选更准的选区再发（agent 靠"原文逐字匹配"定位，选得越准越准） |
| 改完文档没变化 | 点一下正文任意位置触发重绘（WPS 的已知问题）；或看面板是否报了「✗ 未找到…」 |
| 表格里改不动 | 光标要在表格内（面板会显示「附带当前表格」）；改单元格时 `find` 只认单元格里的文字，整行（含 `|`）匹配不到 |
| 端口 3987 被占 | 改 `bridge.js` 里的 PORT 和 `taskpane.js` 里的 BRIDGE 端口 |

## 五、文件说明

| 文件 | 作用 |
|---|---|
| `bridge.js` | 桥接守护进程：pi 子进程管理 + HTTP/SSE + 加载项静态托管（127.0.0.1:3987） |
| `doc-assistant-prompt.md` | 注入 pi 的系统提示（文档编辑专助手 + 6 类输出代码块约定） |
| `pi-assistant/` | WPS 加载项本体（`ui/taskpane.html` 面板、`js/taskpane.js` 逻辑、`ribbon.xml` 功能区） |
| `sessions/` | pi 会话文件（每个文档一条，自动生成，别手动删） |
| `sessions-map.json` | 文档 → 会话文件的映射（自动生成） |
| `tool-log.json` | 每条回复用过哪些工具/技能的记录（供「历史」显示「⚙ 用过 bash」） |
| `bridge-config.json` | 桥接记住的模型配置（有 provider/model 时自动生成，桥接重启后自动拉起 pi） |
| `start-bridge.cmd` | 一键启动桥接（幂等） |
| `ui-helper.ps1` | 调试辅助：截图/点击/裁剪窗口（开发用，日常不需要） |
| `test-e2e.js` / `test-session.js` / `test-skills.js` | 桥接层测试（不经 WPS，纯 HTTP/SSE；`test-skills.js "问题"` 可验证技能与工具） |

**协议要点**：agent 回复里附代码块，侧栏解析后执行。

```json
{"edits":[{"find":"原文逐字片段","replace":"新文字","reason":"为什么这么改"}]}
```

```json
{"comments":[{"find":"原文逐字片段","text":"批注内容"}]}
```

```json
{"rows":[{"after":"锚点行里能唯一识别该行的单元格文字","cells":["第1列","第2列","第3列"]}]}
```

```json
{"images":[{"after":"锚点段落里的一小段文字","path":"D:\\图\\断面图.png","width":12}]}
```

```json
{"tables":[{"after":"锚点段落文字","rows":3,"cols":3,"header":["站名","流量","说明"],"data":[["梅港","1250","正常"],["虎山","980","偏低"]]}]}
```

```json
{"ops":[{"op":"insertColAfter","find":"水位(m)","header":"流量(m³/s)","cells":["1250","980"]}]}
```

`ops` 支持的 op：`merge`（`from`/`to` 两锚点）、`split`（`rows`/`cols`）、`insertColAfter`（`find`+`header`+`cells`）、`deleteRow`、`deleteCol`（`find`）、`formatHeader`、`colWidth`（`find`+`cm`）、`rowHeight`（`find`+`cm`）、`repeatHeader`、`autoFit`。

`find` 必须与文档逐字一致且唯一，侧栏按它定位。找不到会明确报「✗ 未找到」，不会静默乱改。

`wps-edits` 的每条还可带 `mode`：不写=替换；`"insertAfter"`=在 find 所在段落**之后另起一段**（内容为 replace）；`"delete"`=删除 find 这段文字。

## 六、开发模式（改代码时用）

生产模式改完代码要重启 WPS 才能生效（加载项页面在 WPS 里缓存）。要热更新就用 wpsjs 的开发服务：

```powershell
cd "D:\DSH工作区\wps-pi-plugin\pi-assistant"
wpsjs debug      # 起 vite 开发服务 :3889，带 HMR
```

然后把 `%APPDATA%\kingsoft\wps\jsaddons\publish.xml` 里 pi-assistant 的 url 改回 `http://127.0.0.1:3889/`，重启 WPS。日常用不着，别一直开着。
